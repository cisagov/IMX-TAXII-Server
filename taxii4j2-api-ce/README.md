# taxii4j2-api-ce

This module provides
foundation classes implementing data and methods
defined in the TAXII specification
for TAXII server versions.

Refer to either `taxii4j2-ce-sqlite` or `taxii4j2-th-es`
to create and deploy a TAXII server.
