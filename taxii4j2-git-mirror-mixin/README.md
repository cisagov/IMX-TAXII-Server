# taxii4j2-git-mirror-mixin

This module provides
registration, filtered mirroring, and truth management for Git*
repositories of JSON Schema and STIX Objects.

Refer to either `taxii4j2-ce-sqlite` or `taxii4j2-th-es`
to create and deploy a TAXII server.
